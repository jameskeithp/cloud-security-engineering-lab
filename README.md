# Cloud Security Engineering Lab

My public hands-on lab for AWS cloud security engineering — learning in
public. **Status: in progress.** Each lab is a self-contained exercise you
can run in a personal or sandbox AWS account. Never run these against
production.

## Purpose

Turn cloud security concepts into muscle memory: IAM, EC2 hardening,
logging and monitoring, and incident response — the same domains I work
with daily.

## How to use a lab

1. Open the lab's folder and read its `README.md` — it states the goal,
   the commands, and what "done" looks like.
2. Run everything in a **sandbox account** with billing alerts on.
3. All exercises are read-only unless the lab says otherwise.
